Requires two paired measurements around a brief, deliberate ventilation change (e.g. a NICO-type rebreathing maneuver) — not computable from a single snapshot.
Slope (s) is patient-specific and normally provided by the capnography device itself (typically ~2 mL CO2/mmHg/L) — the default here is a rough placeholder, not a validated patient-specific value. If your monitor reports CO directly, prefer that value over this manual calculation.
This does not calculate a CO value — EtCO2/VtCO2 changes correlate with CO trends but aren't a validated conversion to an absolute number. This mode only flags a meaningful change.
